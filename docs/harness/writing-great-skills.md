# Writing Great Skills

Quickstart:

```bash
npx skills add edheltzel/Do-Skills --skill=do-writing-great-skills
```

```bash
npx skills update do-writing-great-skills
```

[Source](https://github.com/edheltzel/Do-Skills/tree/master/skills/harness/do-writing-great-skills)

## What it does

A reference for writing and editing skills: the vocabulary and principles that make a skill predictable. The constraint is the same process every run, not the same output.

It is all reference, not a review procedure. Bold terms resolve in `GLOSSARY.md`. Failure modes (premature completion, duplication, sediment, sprawl, no-op, negation) name writing problems you can check in a skill you are writing or one you already have.

## When to reach for it

You invoke this by typing `/do-writing-great-skills`. The agent will not reach for it on its own.

Reach for it when writing or editing a skill, or when you want those levers on existing skill prose. For turning a source into a new skill, use [do-distill-to-skill](../harness/distill-to-skill.md).

## Predictability

Every lever serves that word: invocation choice, information hierarchy, progressive disclosure, leading words, pruning. The glossary is disclosed reference, loaded when a term needs the full meaning.

## Where it fits

A user-invoked harness reference. Distill extracts; this is the writing vocabulary you load by hand.
