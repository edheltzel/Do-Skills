# Global Skills

Useful in any repo, or none. Install once per machine with `-g`.

## Installation

```bash
npx skills add https://github.com/edheltzel/Do-Skills/tree/master/skills/global -g
```

## Groups

| Group | Skills | Coverage |
|-------|--------|----------|
| [Core](./core/) | 13 | Stack-agnostic foundations - review lenses, reasoning, testing, simplification, agent-legible repos, comments, design patterns, skill authoring, and AI-writing cleanup. |
| [Loop](./loop/) | 6 | The idea-to-PR loop - brainstorm, plan, plan review, work, debug, and the do-it (LFG) runner. Ships through do-commit in Workflow. |
| [Workflow](./workflow/) | 14 | Shipping and collaboration - commits, PR babysitting, review and triage, GitHub projects and stacks, safe PR workflow, worktrees, docs, and technical writing. |
| [Operations](./operations/) | 5 | Operating AI agents - delegation, handoffs, prompt audits, project status check-ins, and skill drift repair. |
| [Content](./content/) | 3 | Audience-facing media - illustrations, diagrams, images, and visual explanations. |
| [Personal](./personal/) | 4 | Personal extras you want everywhere - teaching, todo.txt, isometric explainer figures. |
