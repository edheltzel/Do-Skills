# Design

Brand and media design - your own fonts, logos, and motion graphics videos.

## Installation

Every skill in this group:

```bash
npx skills add https://github.com/edheltzel/Do-Skills/tree/master/skills/project/design
```

One skill by exact name:

```bash
npx skills add edheltzel/Do-Skills --skill=<skill-name>
```

## Skills

| Skill | Description |
|-------|-------------|
| [`do-make-font`](./do-make-font/) | Use when someone wants their own font made from fonts they like, such as "make me a font like these", "/do-make-font" or "build a typeface from these screenshots". |
| [`do-make-logo`](./do-make-logo/) | Use when someone wants a logo, mark or wordmark for their product, such as "make me a logo", "/do-make-logo" or "a logo like these but ours". |
| [`do-make-motion`](./do-make-motion/) | Use when someone wants a motion graphics video of their product (a launch video, feature demo, teaser or explainer), such as "make a launch video for this", "/do-make-motion" or "roast my video idea". |
