# Marketing

SEO marketing on the Ubersuggest MCP - keyword research, site audits, competitors, content briefs, AI visibility, and action plans.

## Installation

Every skill in this group:

```bash
npx skills add https://github.com/edheltzel/Do-Skills/tree/master/skills/project/marketing
```

One skill by exact name:

```bash
npx skills add edheltzel/Do-Skills --skill=<skill-name>
```

## Skills

| Skill | Description |
|-------|-------------|
| [`uber-ai-visibility`](./uber-ai-visibility/) | Report how visible a brand is inside AI answers (ChatGPT, Perplexity, Google AI Overviews, Claude) using Ubersuggest's AI Search Visibility data. |
| [`uber-competitor-analysis`](./uber-competitor-analysis/) | Analyse a domain and its organic competitors, then report the keyword and content gaps. |
| [`uber-content-brief`](./uber-content-brief/) | Build a data-backed content brief for a target keyword by analysing who currently ranks and why. |
| [`uber-content-demand-finder`](./uber-content-demand-finder/) | Turn a business description into 50 customer-driven content opportunities — a Content Demand Map of problem clusters, the questions customers ask, and the articles or videos that answer them. |
| [`uber-keyword-research`](./uber-keyword-research/) | Run a full keyword research pass for a topic, niche, product or business and return a prioritised keyword list grouped into clusters. |
| [`uber-project-setup`](./uber-project-setup/) | Set a website up in Ubersuggest for the first time — create the project, describe the business, pick competitors, choose the topics and prompts tracked in AI answers, and select keywords to rank-track. |
| [`uber-seo-action-plan`](./uber-seo-action-plan/) | Look at a website and decide what its owner should do next about SEO, in plain language, without making them choose. |
| [`uber-seo-foundations`](./uber-seo-foundations/) | Core SEO know-how and the map from a user's goal to the right Ubersuggest MCP tool. |
| [`uber-site-audit`](./uber-site-audit/) | Crawl a site for technical SEO problems and report prioritised fixes with Core Web Vitals. |
